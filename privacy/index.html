Privacy Policy

Last updated: 10 November 2026

This policy covers the website robz.design and Robz Refs, a private tool that Roberto Junior ("Robz", "I") built to work with his own Pinterest account.

robz.design

The website does not use cookies, analytics, or tracking, and it does not ask you for any personal data. It is hosted on GitHub Pages, which may keep standard server logs (such as IP addresses) under GitHub's privacy statement. If you email me, I use your message only to reply to you.

Robz Refs (Pinterest integration)

Robz Refs connects to the Pinterest API only for my own Pinterest account. It is not offered to other users.

  • What it accesses: my own account profile, boards, board sections and Pins (titles, descriptions, links and image URLs). When I explicitly ask it to, it can create boards or Pins on my own account.
  • How data is stored: access tokens are kept in the macOS Keychain on my computer. Pin metadata and images are saved only to local folders on my computer, for my own creative projects.
  • Sharing: no data is sold, shared with third parties, or used for advertising.
  • Other users: the tool does not access data from any Pinterest account other than mine.
  • Revoking access: access can be revoked at any time in Pinterest settings under connected apps, and local data can be deleted at any time.
